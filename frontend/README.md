# フロントエンド（画面）

React（TypeScript）＋ Vite ＋ Tailwind CSS v4 で作った画面です。

| コマンド | 内容 |
|---|---|
| `npm install` | 必要な部品を取ってくる（最初に1回） |
| `npm run dev` | 開発用サーバーを起動する（`http://localhost:5173`） |
| `npm run build` | 型のチェックをしてから、完成版のファイルを `dist` フォルダに作る |
| `npm run typecheck` | 型のチェックだけをする（TypeScript） |
| `npm test` | テスト（Vitest）を実行する |
| `npm run lint` | プログラムの書き方をチェックする（oxlint） |

全体の起動方法は、ルートの [README](../README.md) を参照してください。

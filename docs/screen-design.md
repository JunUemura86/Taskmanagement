## 1. 画面の一覧

| ID | 画面名 | 説明 |
|---|---|---|
| SC-01 | メイン画面（ボード） | リストとカードを表示する。ほとんどの操作はこの画面で行う |
| SC-02 | カード編集画面 | カードをクリックすると、メイン画面の上に重ねて表示する小さな画面（背景を押しても閉じない） |
| SC-03 | 確認メッセージ | 削除の前に「よろしいですか？」と聞く小さな画面（アプリの中に作ったもの。ほかの画面の上に重ねて表示し、「キャンセル」と「削除」のボタンを置く。Esc は「キャンセル」と同じ。背景を押しても閉じない） |

## 2. 画面の移り変わり

```
SC-01 メイン画面
  │
  ├─ カードをクリック ─────────→ SC-02 カード編集画面
  │                                ├─「保存」「×」Esc → SC-01 に戻る
  │                                └─「削除」→ SC-03 確認 → SC-01 に戻る
  │
  ├─「…」→「リストを削除」───→ SC-03 確認 → SC-01 に戻る
  │
  └─「選択したカードを削除」──→ SC-03 確認 → SC-01 に戻る
```

## 3. SC-01 メイン画面

```
┌─────────────────────────────────────────────────────────────────────┐
│ ◆ タスク管理 | 3リスト・5カード           [選択したカードを削除（2件）] │ ← ヘッダー
├─────────────────────────────────────────────────────────────────────┤
│ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐ ┌┄┄┄┄┄┄┄┄┄┄┄┄┄┄┐ │
│ │⠿□ 未着手 2  … │ │⠿□ 進行中 1  … │ │⠿□ 完了 ✓2  … │ ┊＋ リストを追加┊ │
│ │ 並べ替え…   ▼│ │ 並べ替え…   ▼│ │ 並べ替え…   ▼│ └┄┄┄┄┄┄┄┄┄┄┄┄┄┄┘ │
│ ├──────────────┤ ├──────────────┤ ├──────────────┤                  │
│ │▓▓▓           │ │▓▓▓           │ │☑ 請求書      │                  │
│ │□ 資料作成    │ │□ 会議準備    │ │  [↑高] 10/20 │                  │
│ │  [↑高] 11/10 │ │  [→中] 11/03 │ ├──────────────┤                  │
│ ├──────────────┤ └──────────────┘ │▓▓▓           │                  │
│ │□ メール      │                  │☑ 見積書      │                  │
│ │  [→中] 期限切│                  │  [→中]       │                  │
│ │   れ 10/30   │                  └──────────────┘                  │
│ ├──────────────┤                                                    │
│ │＋ カードを追加│                                                    │
│ └──────────────┘                                                    │
└─────────────────────────────────────────────────────────────────────┘
```

| 部品 | 説明 |
|---|---|
| ヘッダー | アプリのアイコンとアプリ名、リストとカードの数（読み込めたときだけ）、「選択したカードを削除（○件）」ボタン。複数のリストにまたがって選べるため、ボタンは画面上部に1つだけ置く。1枚も選んでいないときは押せない |
| リストの見出し | つまみ（⠿）、「すべて選択」のチェックボックス、リスト名、完了用なら「✓」、カードの枚数、「…」メニュー |
| つまみ（⠿） | リストの見出しの左端に置く。マウスを乗せると手の形（つかむ形）のカーソルになり、押したまま左右にドラッグするとリストの順番を変えられる（UC-13）。リストのほかの場所を押しても、リストは動かない |
| 並べ替えのプルダウン | リストの見出しのすぐ下に置く。最初は「並べ替え…」と表示し、「優先度順」「期限順」「カテゴリ別」「追加した順」から選ぶ。カードが1枚以下のときは押せない |
| 「…」メニュー | 「完了用リストにする／解除」「リストを削除」。押し間違いを防ぐため、リストの削除はこのメニューの中に置く |
| カード | ラベルの帯、チェックボックス、タイトル、優先度のバッジ、期限（下の「カードの表示」を参照） |
| ＋カードを追加 | 各リストの一番下に置く（＋はアイコン）。カードが1枚もないリストには、その上に「カードはまだありません」と表示する |
| ＋リストを追加 | リストの並びの一番右に置く（＋はアイコン）。リストが多いときは横にスクロールする |

### カードの表示

ラベル（カテゴリ）と優先度はどちらも色を使うため、**置き場所と形を分けて**、色が混ざって見えないようにする。

```
┌──────────────────────────┐
│ ▓▓▓                      │ ← ラベル：タイトルの上の短い色の帯
│ □ 資料作成               │
│   [↑ 高]  11/10          │ ← 優先度：文字入りのバッジ ／ 期限：カレンダーのアイコンと日付
└──────────────────────────┘
```

| 部品 | 置き場所・形 | 説明 |
|---|---|---|
| ラベル（カテゴリ） | タイトルの上の短い帯（太さ6ピクセル、長さ40ピクセル） | 赤・黄・緑・青・紫のどれか。ラベルなしのときは帯を出さない。帯にマウスを乗せると「ラベル：赤」のように名前を表示する |
| 優先度 | タイトルの下の行の左の、角の丸いバッジ | 「↑ 高」「→ 中」「↓ 低」の文字と色で表示する（色は [機能要件](functional-requirements.md) の「2.5 優先度のルール」を参照）。高だけ濃い色にして、大事なカードが一目で分かるようにする |
| 期限 | タイトルの下の行、優先度の右 | 左にカレンダーのアイコンを付ける。期限の色分けは [機能要件](functional-requirements.md) の「2.3 期限の色分けのルール」を参照 |

## 4. SC-02 カード編集画面

```
┌────────────────────────────────┐
│ カードの編集                 × │
│                                │
│ タイトル（必須）                 │
│ [ 資料作成                   ] │
│                                │
│ 優先度                          │
│ [  ↑ 高  ] [  → 中  ] [  ↓ 低  ] │
│                                │
│ 期限                            │
│ [ 2026/11/10 ]  クリア          │
│                                │
│ ラベル                          │
│ (なし) ●赤 ●黄 ●緑 ●青 ●紫       │
├────────────────────────────────┤
│ 削除                     [保存] │
└────────────────────────────────┘
```

| 部品 | 説明 |
|---|---|
| 優先度 | 高・中・低の3つのボタンから1つを選ぶ。選んでいるボタンはその優先度の色にして紫の枠で囲み、選んでいないボタンは白い背景にする |
| 期限 | 押すとカレンダーを開く。日付を押すと、その日を選んでカレンダーを閉じる。年と月は、カレンダーの上のプルダウンで変えられる（今年の前後10年）。矢印キーと Enter でも選べる。Esc はカレンダーだけを閉じる。「クリア」で期限なしにする（「期限なし」と表示する） |
| ラベル | 「なし」と5色から1つを選ぶ。選んでいるものは紫の枠で囲み、色にはチェックの印を出す。色にマウスを乗せると名前（赤・黄など）を表示する |
| 保存 | 押すと保存して、編集画面を閉じる。タイトルの入力欄で Enter キーを押しても保存する。保存している間は「保存中…」と表示し、「保存」「削除」を押せなくする（二重に保存しないため） |

## 5. メッセージの一覧

| ID | 種類 | 表示する場面 | メッセージ |
|---|---|---|---|
| M-01 | 確認 | カードを1枚削除するとき | カード「（タイトル）」を削除します。よろしいですか？ |
| M-02 | 確認 | 選んだカードをまとめて削除するとき | 選択した（件数）件のカードを削除します。よろしいですか？ |
| M-03 | 確認 | リストを削除するとき | リスト「（リスト名）」を削除します。中のカード（件数）件も削除されます。よろしいですか？ |
| M-04 | エラー | リスト名が空のとき | リスト名を入力してください。 |
| M-05 | エラー | カードのタイトルが空のとき | タイトルを入力してください。 |
| M-06 | エラー | リストが10個あるのに追加しようとしたとき | リストは最大10個まで作成できます。 |
| M-07 | エラー | 100枚あるリストにカードを追加・移動しようとしたとき | 1つのリストに入れられるカードは最大100枚です。 |
| M-08 | エラー | サーバーやDBにつながらないとき | サーバーに接続できませんでした。サーバーが起動しているか確認してください。 |

## 6. メッセージの出し方

| 種類 | 対象 | 出し方 |
|---|---|---|
| 削除の確認 | M-01〜M-03 | アプリの中の確認画面（SC-03）。ブラウザ標準の確認画面は、ブラウザによっては出ないため使わない |
| 入力エラー | M-04、M-05 | 入力欄のすぐ下に赤い文字で表示する |
| 上限・接続エラー | M-06〜M-08 | 画面上部にお知らせ欄を表示する |

- 文字数の上限（リスト名30文字、タイトル100文字）を超える入力は、入力欄に打ち込めないようにする（メッセージは出さない）
- 画面上部のお知らせ欄（M-06〜M-08）は、次の操作が成功すると消える
- 画面を開いたときにボードを読み込めなかったときは、M-08 だけを表示し、ボードは表示しない（ページを開き直すまで消えない）

## 7. 配色

白を基調にして、紫（ラベンダー系）はボタンや選択中などの要所にだけ使う。目が疲れる強い色は使わない。色コードは `frontend/src/index.css` にまとめ、部品には直接書かない。

| 名前 | 色 | 使う場所 |
|---|---|---|
| board | `#FCFCFD` | ボードの背景 |
| list | `#E7E5EE` | リストの背景 |
| list-line | `#CFCBDD` | リストの枠線、リストの中の区切り線 |
| line | `#E2DFEC` | カードの枠線、区切り線 |
| input-line | `#8E8AA3` | 入力欄の枠線、「＋リストを追加」の点線 |
| soft | `#F3F2F7` | 控えめなボタンの背景、優先度「低」のバッジの背景 |
| hover | `#DEDBE8` | マウスを乗せたとき |
| ink | `#1F1D2B` | 本文の文字、重ねる画面のうしろの幕（40％の濃さ） |
| sub | `#625F72` | 補助の文字 |
| primary / primary-dark | `#6D5BB8` / `#5A489F` | アプリのアイコン、「保存」ボタン、選択中の枠 / マウスを乗せたとき |
| danger / danger-dark / danger-soft | `#BF4A5A` / `#A63C4B` / `#FDECEF` | 削除のボタン、優先度「高」 / マウスを乗せたとき、期限切れなどの赤い文字 / お知らせ欄の背景 |
| warn / warn-soft | `#6F5500` / `#FBF1C9` | 期限が近い日付の文字 / 背景 |
| mid / mid-soft | `#8A4B12` / `#FDF3E7` | 優先度「中」の文字 / 背景 |
| done | `#2B7054` | 完了用リストの「✓」 |

- カードの背景とヘッダーの背景は白にする
- リストは、背景との明るさの差に加えて、枠線・影・リストどうしのすき間で、分かれて見えるようにする
- リストの見出し・並べ替えのプルダウンと、カードの並びの間に区切り線を入れる
- チェックボックスで選んだカードは、紫の枠で囲む
- 「＋リストを追加」は点線の枠にして、リストと区別する
- ボタン・お知らせ欄などの部品は shadcn/ui、アイコンは Lucide を使う。文字は、英数字に Inter、日本語に Noto Sans JP を使う（[技術スタック](tech-stack.md) を参照）
- ラベルの5色は [データベース設計書](database-design.md) の「5. ラベル表の最初のデータ」を参照

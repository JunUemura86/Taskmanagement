## 1. 共通のルール

| 項目 | ルール |
|---|---|
| URL の始まり | `http://localhost:8080/api` |
| やり取りする形 | JSON（文字コードは UTF-8） |
| 項目名 | キャメルケース（例：`dueDate`、`colorCode`） |
| 日付 | `YYYY-MM-DD` の形（例：`2026-11-10`）。ないときは `null` |
| 並び順 | リスト・カード・ラベルとも、`position` の小さい順に返す |
| CORS（画面からの呼び出しの許可） | 画面の `http://localhost:5173` と `http://127.0.0.1:5173` からの呼び出しだけを許可する。メソッドは GET・POST・PUT・PATCH・DELETE。ほかの場所からの呼び出しは 403 Forbidden になる（設定：`backend/src/main/java/com/example/taskmanagement/config/WebConfig.java`） |

## 2. API の一覧

| No. | メソッド | URL | 内容 | 対応する機能 |
|---|---|---|---|---|
| A-01 | GET | `/api/board` | リストと、その中のカードをまとめて返す | F-01 |
| A-02 | GET | `/api/cards/{id}` | カードを1枚返す | F-05 |
| A-03 | GET | `/api/labels` | ラベルの一覧を返す | F-05 |
| A-04 | POST | `/api/cards` | カードをリストの一番下に追加する | F-04 |
| A-05 | POST | `/api/lists` | リストを一番右に追加する | F-09 |
| A-06 | PUT | `/api/cards/{id}` | カードのタイトル・優先度・期限・ラベルを変更する | F-05 |

## 3. API の詳細

### A-01 ボードの取得 `GET /api/board`

**返す内容（200 OK）**

```json
[
  {
    "id": 1,
    "name": "未着手",
    "position": 0,
    "isDone": false,
    "cards": [
      {
        "id": 1,
        "listId": 1,
        "labelId": 1,
        "title": "買い物に行く",
        "priority": 1,
        "dueDate": "2026-11-10",
        "position": 0
      }
    ]
  }
]
```

| 項目 | 内容 |
|---|---|
| `id` / `name` / `position` | リストの ID・名前・並び順 |
| `isDone` | 完了用リストなら `true` |
| `cards` | そのリストのカード。カードがないときは空（`[]`） |

### A-02 カードの取得 `GET /api/cards/{id}`

**返す内容（200 OK）**

```json
{
  "id": 1,
  "listId": 1,
  "labelId": 1,
  "title": "買い物に行く",
  "priority": 1,
  "dueDate": "2026-11-10",
  "position": 0
}
```

| 項目 | 内容 |
|---|---|
| `labelId` | ラベルなしのときは `null` |
| `priority` | 1（高）・2（中）・3（低） |

**エラー**

| 状態 | ステータス |
|---|---|
| その ID のカードがない | 404 Not Found |

### A-03 ラベルの取得 `GET /api/labels`

**返す内容（200 OK）**

```json
[
  { "id": 1, "name": "赤", "colorCode": "#E5484D", "position": 0 }
]
```

### A-04 カードの追加 `POST /api/cards`

**送る内容**

```json
{ "listId": 1, "title": "買い物に行く" }
```

| 項目 | 必須 | ルール |
|---|---|---|
| `listId` | 必須 | カードを入れるリストの ID |
| `title` | 必須 | 1〜100文字。改行は入れられない。前後の空白は取り除いて保存する |

- 登録時はタイトルだけを送る（UC-02）。優先度は 2（中）、期限・ラベルは `null` で保存する
- リストの一番下に追加する（`position` は、そのリストで一番大きい値＋1。カードがなければ 0）

**返す内容（201 Created）**：作ったカード（A-02 と同じ形）

```json
{
  "id": 7,
  "listId": 1,
  "labelId": null,
  "title": "買い物に行く",
  "priority": 2,
  "dueDate": null,
  "position": 3
}
```

**エラー**

| 状態 | ステータス | 画面のメッセージ |
|---|---|---|
| タイトルが空・101文字以上・改行入り、`listId` がない | 400 Bad Request | M-05（空のときは画面で先に止める） |
| その ID のリストがない | 404 Not Found | M-08 |
| リストにカードがすでに100枚ある | 409 Conflict | M-07 |

### A-05 リストの追加 `POST /api/lists`

**送る内容**

```json
{ "name": "確認待ち" }
```

| 項目 | 必須 | ルール |
|---|---|---|
| `name` | 必須 | 1〜30文字。改行は入れられない。前後の空白は取り除いて保存する。同じ名前のリストも作れる |

- 一番右に追加する（`position` は、一番大きい値＋1。リストがなければ 0）
- 完了用リストにはしない（`isDone` は `false`）

**返す内容（201 Created）**：作ったリスト（A-01 のリスト1つと同じ形。`cards` は空）

```json
{
  "id": 4,
  "name": "確認待ち",
  "position": 3,
  "isDone": false,
  "cards": []
}
```

**エラー**

| 状態 | ステータス | 画面のメッセージ |
|---|---|---|
| リスト名が空・31文字以上・改行入り | 400 Bad Request | M-04（空のときは画面で先に止める） |
| リストがすでに10個ある | 409 Conflict | M-06 |

### A-06 カードの変更 `PUT /api/cards/{id}`

**送る内容**

```json
{ "title": "資料作成", "priority": 1, "dueDate": "2026-11-20", "labelId": 3 }
```

| 項目 | 必須 | ルール |
|---|---|---|
| `title` | 必須 | 1〜100文字。改行は入れられない。前後の空白は取り除いて保存する |
| `priority` | 必須 | 1（高）・2（中）・3（低） |
| `dueDate` | 任意 | `YYYY-MM-DD` の形。期限なしは `null`。過去の日付も入れられる |
| `labelId` | 任意 | ラベルの ID。ラベルなしは `null` |

- 4つの項目を毎回すべて送る（送らなかった項目は `null` として扱う）
- リストと並び順は変えない

**返す内容（200 OK）**：変更したあとのカード（A-02 と同じ形）

**エラー**

| 状態 | ステータス | 画面のメッセージ |
|---|---|---|
| タイトルが空・101文字以上・改行入り、優先度が 1〜3 以外、ないラベルの ID | 400 Bad Request | M-05（空のときは画面で先に止める） |
| その ID のカードがない | 404 Not Found | M-08 |

# 画面モック（プロトタイプ）

[画面設計書](../docs/screen-design.md) の画面イメージを、ブラウザで実際に見て確認するための試作品です。本番のアプリではありません。

## 開き方

`index.html` をダブルクリックして、ブラウザで開きます（サーバーは不要です）。

## 注意

- データは保存されません。ページを読み込み直すと、最初の状態に戻ります。
- 期限の日付は「今日」を基準に作っているため、いつ開いても赤・黄・通常の色分けを確認できます。
- 上限チェック（M-06、M-07）と接続エラー（M-08）の動きは入れていません。画面上部のお知らせ欄は、見た目の確認用に表示例を出しています。
